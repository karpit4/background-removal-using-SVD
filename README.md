# Video Background Removal using SVD

Программа для выделения **статического фона и движущихся объектов на видео** с использованием методов низкорангового приближения матриц и сингулярного разложения (SVD).

Видео представляется в виде матрицы, после чего с помощью SVD строится низкоранговое приближение, которое интерпретируется как фон. Разность между исходным видео и восстановленным фоном используется для выделения движущихся объектов.

## Используемые алгоритмы

В проекте реализованы два алгоритма:

* **Truncated SVD** — точное усечённое SVD:

  ```python
  U, S, Vt = trunc_svd(M, r)
  ```

* **Randomized SVD** — приближённое рандомизированное SVD с oversampling:

  ```python
  U, S, Vt = rand_svd(M, r, oversampling=10)
  ```

Полученное приближение матрицы имеет вид:

```text
M_r = U Σ Vᵀ
```

где `r` — выбранный ранг приближения.

## Запуск

Установите необходимые зависимости:

```bash
pip install numpy matplotlib pillow opencv-python moviepy
```

Затем запустите:

```bash
python src/main.py
```

Перед запуском убедитесь, что исходное видео находится в папке `videos/`, а папка `results/` существует.

Путь к входному файлу задаётся в `src/main.py`:

```python
path = "videos/driveway-320x240.avi"
```

Программа также поддерживает папку с отдельными кадрами (`.png`, `.jpg`, `.jpeg`, `.ppm`).



## Результаты

После выполнения программы в папке `results/` создаются:

```text
background.mp4   # восстановленный фон
foreground.mp4   # выделенные движущиеся объекты
```

Также отображается сравнение первого кадра исходного видео, восстановленного фона и выделенных движущихся объектов.

## Ограничения

Метод наиболее эффективен для видео с относительно **неизменным фоном** и движущимися объектами. Если фон сам существенно изменяется, низкоранговое приближение может некорректно разделять фон и движущиеся объекты.
